# Watermelon Battle

一个基于 HTML5 和 PeerJS 的在线合成大西瓜对战游戏。

## 一键部署到 Vercel

本项目已支持静态站点部署，直接将仓库连接到 Vercel 即可上线。

如果你已经在 GitHub 上托管此仓库，可以使用下面的按钮（请替换为你的仓库地址）：

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/project?repository-url=https://github.com/<你的用户名>/<你的仓库>)

## 直接部署步骤

1. 将本项目推送到 GitHub。
2. 登录 Vercel，选择 **New Project**。
3. 连接到你的 GitHub 仓库。
4. 选择默认设置并部署。

## 本地运行

直接打开 `index.html` 即可本地试玩。

## 说明

- `index.html` 是主页面。
- `watermelon-battle.png` 是水果雪碧图。
- `vercel.json` 已配置为静态部署并将所有路由重写到 `index.html`。
